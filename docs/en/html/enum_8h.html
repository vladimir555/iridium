Defines a class that encapsulates a scoped enum, providing type safety and utility functions. This macro generates a class TEnum with an internal enum, providing constructors from the underlying type, integers, and strings. It also includes conversions to std::string and the internal enum type, along with static methods for introspection (e.g., getting all enum values) and conversion.

Parameters
TEnumThe name of the enum class to be defined.
...A comma-separated list of enumerator definitions (e.g., VALUE1, VALUE2, VALUE3 = 10).
