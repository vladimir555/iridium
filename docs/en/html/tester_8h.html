class  iridium::testing::Tester
 Singleton class responsible for registering, managing, and running all tests within the framework. It collects test cases defined using the TEST macro and provides a run method, typically invoked by a main function generated by IMPLEMENT_TEST_MAIN. The Tester can filter tests based on command-line arguments and organizes tests, potentially in a tree structure, for execution. More...

Macros

#define TEST(name)
 Defines a test case and registers it with the Tester singleton. This macro generates a unique class named Test_##name that inherits from ::iridium::testing::ITest and iridium::testing::UnitTest. An instance of this class is automatically created, and its constructor registers the test with Tester::instance(). The user should provide the body of the void Test_##name::run() method immediately following this macro invocation.
